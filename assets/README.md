# Assets Folder

This folder is reserved for image assets (logos, photographs, illustrations).

The Sweet & Art Bakery website uses **CSS-generated placeholders** instead of real images — colorful gradients with candy emoji icons represent each sweet treat in the menu. This keeps the project lightweight and avoids any external image dependencies.

If you want to add real photos in the future, place them here and reference them from `index.html` or `styles.css`.
